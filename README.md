# 🎁 Surpriso – Basket & Box

A beautiful and interactive gift customization website designed for **Surpriso**, a personalized gifting brand based in Lahore, Pakistan.

The website allows visitors to explore creative gift collections, customize their gift preferences, select add-ons, and contact the brand directly through Instagram DM.

## ✨ Features

- 🌸 Elegant and attractive landing page
- 🎁 Customized gift boxes and baskets showcase
- 💐 Gift collections with product descriptions
- 🎨 Interactive gift selection builder
- ✨ Custom gift option with personal descriptions
- 🎀 Multiple add-ons selection
- 💌 Automatically generated Instagram DM messages
- 📱 Fully responsive mobile-friendly design
- 🌙 Light and dark theme support
- 💖 Animated intro screen and floating hearts
- Smooth scrolling and reveal animations
- Accessibility and reduced-motion support

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- SVG Graphics

## 🎨 Design Highlights

- Soft orchid and blush color palette
- Elegant typography
- Beautiful floral-inspired elements
- Smooth animations and transitions
- Clean and modern user interface

## 🚀 How It Works

1. Explore the available gift collections.
2. Select your preferred gift type.
3. Choose additional items such as chocolates, roses, balloons, or custom note cards.
4. Describe your own gift idea if you want something unique.
5. Generate a personalized message.
6. Continue directly to Surpriso's Instagram DM.
